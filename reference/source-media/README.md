# Source media

This directory preserves original, full-quality media that is too large for
direct production delivery. Files under `public/assets/` are web derivatives;
the originals here remain the archival reference.

- `Bible Translation Record 2014-05-21-original.mp4` is the untouched 1920×1080,
  39.04-second recording previously served directly by the site.
- `bible_story-original.mp4` is the untouched local copy of the Bible Stories
  video still embedded from the archived Wistia source.
- `splash-background-original.mp4` is the unused original homepage motion asset.
